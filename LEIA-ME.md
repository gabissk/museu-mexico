# MIRA — Museu México

## Arquivos principais
- `index.html`: página inicial com destaques editoriais.
- `historia.html`, `povos-indigenas.html`, `religiao.html`, `cultura.html`, `simbolos-patrimonio.html`: páginas independentes das cinco coleções.
- `artigo.html?id=...`: modelo de artigo; cada card abre a matéria completa pelo ID.
- `quizzes.html`: página separada de quizzes (estrutura inicial; quizzes serão adicionados depois).
- `fontes.html`: fontes gerais.
- `articles.js`: dados das 30 matérias extraídos do documento editorial.
- `style.css`: identidade visual responsiva.
- `script.js`: menu mobile, artigos dinâmicos e busca.

## Publicação no GitHub Pages
Envie os arquivos desta pasta para a raiz do repositório, substituindo os arquivos antigos com o mesmo nome. O arquivo `logo-mira.png` foi mantido sem alteração nesta versão, conforme solicitado.

## Imagens e direitos
As matérias incluem sugestões de imagem e fontes, não imagens externas automaticamente reutilizáveis. Confirme a licença, autoria e atribuição de cada imagem antes de publicar.
